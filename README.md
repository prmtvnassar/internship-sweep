# internship-sweep

Daily sweep of public job-board APIs (Greenhouse, Lever, Ashby) and the community lists
SimplifyJobs/Summer2027-Internships and vanshb03/Summer2027-Internships for hardware, FPGA,
ASIC, photonics and quantum internships, plus technical internships in Tennessee.

`state/opps.json` holds only open postings: a posting leaves when its board stops listing it or
its deadline passes. New postings go to a Discord channel. Stdlib Python, no dependencies.
